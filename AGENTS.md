# agflow

This repository distributes the current skill-based development workflow,
portable user instruction blocks, harness-driven setup instructions and an interactive HTML
diagram of the current process.

## Working here

- Read README.md for repository layout and commands. For a request to install or
  recreate or update this workflow on a machine, follow [BOOTSTRAP.md](BOOTSTRAP.md).
- Preserve unrelated user files and existing destination configuration. Never
  add credentials, personal provider profiles, session history or machine paths.
- Keep the five skills self-contained, with referenced resources bundled. Keep
  one authoritative source in skills/; do not edit installed copies as source.
- Installation must be previewable, repeatable and backed up. Test changes in
  temporary homes; never use the real user home as a test fixture.
- Installation and updates are performed by the harness using BOOTSTRAP.md;
  do not add a standalone installer unless requested. Validate the inventory,
  bundled resource links and agreement between setup documents after changes.
  Structural checks are not behavioral qualification. Paid reviews/evaluations
  need their own authorization and must preserve existing aggregate budgets.
- Select review by task risk and explicit user rules; specification review, when
  needed, is one architectural pass. Use the applicable review adapter and preserve
  existing histories, explicit limits and publication rules.
- Make all task changes, including preparation, in a separate worktree. A separate
  working session is also mandatory, including for minor fixes and preparation.
  In Guild use a visible managed worker; assigned workers reuse their session/tree.
  Native helpers do not replace that session; unavailable session capability blocks
  implementation rather than allowing a root fallback.
- Keep the HTML process diagram local and explanatory; its controls must not
  launch models, Git mutations or live reviews.
- Push, remote creation, publication and deployment require explicit permission.
  No automatic installation starts merely from opening this repository.

Write repository documentation and code in English. Communicate with this user
in Russian. Current project-specific instructions take precedence over packaged
example policies; bootstrap does not grant additional host tool permissions.
